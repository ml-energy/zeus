# Code of Conduct

Zeus adopts the [Linux Foundation Projects Code of Conduct](https://lfprojects.org/policies/code-of-conduct/) as its standard of behavior.
It applies to everyone who takes part in the project, in every space the project uses: GitHub issues and pull requests, the Slack workspace, email, and any meeting or event held in the project's name.

## Reporting

If you experience or witness behavior that violates this Code, email conduct@ml.energy.
This reaches the maintainers privately.

If your concern involves a maintainer, you may instead contact any other maintainer listed in [MAINTAINERS.md](/MAINTAINERS.md) directly.

Please include whatever information you have, along with links to any publicly visible material.
Reports are handled privately.
We will work toward a fair resolution, and the project reserves the right to remove anyone from participation where that is warranted.

Security vulnerabilities are handled separately; see [SECURITY.md](/SECURITY.md).
